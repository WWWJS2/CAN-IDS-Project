# تشغيل مشروع كشف التسلل القابل للتفسير

هذا المشروع يعيد استخدام النماذج الثمانية المحفوظة ويشغّل SHAP وLIME على عينات اختبار حقيقية من CICIoV2024 وCar-Hacking. لا تُستخدم ملفات `tests/fixtures` لإنتاج النتائج العلمية.

## المتطلبات

- Python 3.11
- مساحة قرص كافية للبيانات الخام والمجهزة
- تثبيت الحزم: `python -m pip install -r requirements.txt`

## ترتيب التشغيل

1. نزّلي البيانات الأصلية: `python src/download_sources.py ciciov2024 --root data/raw` ثم `python src/download_sources.py car_hacking --root data/raw`.
2. قارني بصمات الملفات مع `metadata/datasets/*/audit.json`.
3. جهّزي البيانات الكاملة داخل `runs`: `python src/prepare_streaming.py --manifest config/ciciov2024.json --output runs/ciciov2024 --seed 42`، ثم كرري الأمر لملف `config/car_hacking.json`.
4. أنشئي تدقيق التقسيم المرجعي: `python src/verify_prepared.py runs/ciciov2024` ثم `python src/verify_prepared.py runs/car_hacking`.
5. تحققي من النماذج المحفوظة: `python run_stage2.py --skip-training`.
6. شغّلي التفسيرات والمقارنة: `python run_xai.py`.
7. شغّلي الاختبارات: `python -m pytest -q`.

توجد إعدادات عينة التفسير والبذور وعدد تكرارات LIME وخط أساس تغيير الخصائص في `config/xai_protocol.json`. تحفظ النتائج الرقمية والرسومات في `results/xai`، وسجلات التنفيذ في `logs`.

ملاحظة منهجية: استبدال الخاصية بوسيط التدريب يبقي القيمة داخل النطاق العددي المرصود، لكنه قد ينتج تركيبة CAN لم تظهر في التسجيل الأصلي. لذلك يُستخدم قياس Faithfulness كاختبار حساسية محلي محدود، وليس كبرهان سببي أو فيزيائي.

## التحقق من نسخة التسليم

- فحص سلامة الملفات العلمية الأساسية دون الحاجة إلى تنزيل البيانات: `python verify_package.py`
- بعد تنزيل ملفات CSV الأصلية، التحقق من بصمات SHA-256 لكل ملف متاح: `python verify_package.py --check-raw`
- تشغيل الاختبارات كاملة بعد تثبيت المكتبات في بيئة Python 3.11: `python -m pytest -q`
- جميع ملفات `models/` والنتائج الحالية تخص التجارب المسجلة سلفًا، ولا يجوز اعتبار نجاح التحقق من الملفات دليلًا على إعادة التدريب.
- استخدمت تجارب Car-Hacking عينة تدريب طبقية من 750,000 سجل من أصل 11,595,074 سجلًا في القسم التدريبي المرجعي. تفاصيل الفئات موجودة في `results/model_training/sampling.json`. احتفظت تجارب CICIoV2024 بجميع سجلات التدريب المرجعية البالغ عددها 985,117 سجلًا.
- الدقة المرتفعة تخص تقسيمات داخل التسجيلات المستخدمة، وقد توجد أنماط CAN متكررة عبر التدريب والتحقق والاختبار؛ لذلك لا تثبت النتائج التعميم على سيارات أو جلسات تسجيل مستقلة.
- تعتمد إعادة تشغيل التفسير SHAP/LIME على وجود `runs` المجهزة وعلى المكتبات المثبتة. لا يُفترض وجود البيانات الخام ضمن هذه الحزمة.
